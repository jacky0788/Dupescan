# DupeScan — 重複檔案掃描工具

> 比對檔案內容，找出完全相同的重複檔案，釋放硬碟空間。**不會永久刪除任何檔案**：移除的檔案一律送到資源回收筒或隔離資料夾，都可以還原。

## 功能特色

- **三個畫面、按鈕很少**：開始（選資料夾）→ 掃描中（只有暫停、停止）→ 結果（每份檔案一顆「保留／移除」膠囊）
- **自動選好要保留哪一份**：保留原始檔名、保護的資料夾一律保留、優先移除 Downloads 這類資料夾裡的副本，其他情況保留最舊／最新／路徑最短的；每組都至少保留一份
- **比對快**：先比大小，再比開頭（大檔再比結尾）4 KB，最後才整檔比對；4 KB 以下的小檔不必讀第二次；SSD 平行讀取、HDD 依路徑順序讀取，多顆磁碟同時進行
- **雜湊快取**：比對過的檔案記起來，重掃同一個地方幾乎不必再讀
- **中斷了可以繼續**：停止、出錯、當機、直接關閉視窗都沒關係，下次開啟按「繼續掃描」，已比對過的檔案不必重讀
- **當機與錯誤都有交代**：錯誤會說明發生什麼事、可以複製錯誤內容；上次沒有正常關閉時會提示，並留下當機紀錄
- **安全**：只會移到資源回收筒或隔離資料夾；移除前再檢查一次檔案有沒有變動；系統與程式資料夾預設不動
- 不會被 junction、符號連結或硬連結騙：同一個實體檔經由不同路徑看到，不會被列成「重複」
- 匯出 HTML 報表、CSV；儲存結果之後再接著處理

## 安裝說明

### 一鍵啟動（推薦）

下載專案後，直接雙擊 **`run.bat`**。腳本會：

1. 確認 Python 3.11+ 已安裝（沒有時會提示下載連結）
2. 第一次執行時在專案內建立虛擬環境 `.venv` 並安裝相依套件（需要網路；套件不會裝進全域 Python）
3. 之後只有 `requirements.txt` 變動才重新安裝，直接啟動 DupeScan（不留命令列視窗）

> 安裝 Python 時請勾選「**Add Python to PATH**」。想看命令列的訊息時執行 `run.bat debug`。
> 相依套件壞掉時，刪除 `.venv` 資料夾再執行一次 `run.bat` 即可重建。

### 手動執行

```bash
pip install -r requirements.txt
python main.py
```

| 套件 | 用途 |
|------|------|
| `PyQt6` | 圖形介面 |
| `xxhash` | 高速檔案 Hash（xxh3_128；沒有時自動改用內建的 blake2b） |

## 怎麼用

### 1. 開始

```
┌ DupeScan ─────────────────────────────────────────────── ⋯ ┐
│  ┌ 上次的掃描沒有完成 ──────────────── [捨棄] [繼續掃描] ┐  │
│  │ D:\Photos 等 2 個資料夾 · 停在第 3 步（63%）            │  │
│  └─────────────────────────────────────────────────────────┘  │
│  找出重複的檔案                                               │
│  要掃描的資料夾                                               │
│   📁 D:\Photos                                          ✕     │
│   📁 E:\Backup                                          ✕     │
│  [＋ 加入資料夾]                                              │
│  要比對的檔案                                                 │
│  (全部) (圖片) (影片) (音樂) (文件) (壓縮檔) (AI 模型) (自訂…)│
│  檔案大小 [100 KB 以上（建議）▾]                              │
│  › 進階選項                                                   │
│                                              [  開始掃描  ]   │
│  上次的結果：D:\Photos 等 2 個資料夾 · 128 組重複   [開啟]    │
└───────────────────────────────────────────────────────────────┘
```

- **資料夾**：按「＋ 加入資料夾」，或直接把資料夾拖進清單；按 ✕ 移除。上下層的資料夾會自動合併，不會掃兩次。找不到或沒有權限讀取的資料夾，按「開始掃描」時會在那一列標紅說明
- **檔案類型**：「全部」或任選幾類；選「自訂…」可以輸入其他副檔名（例如 `psd, blend`）
- **檔案大小**：預設略過 100 KB 以下的檔案（小檔案通常不值得清理，略過可以快很多）；也可以選「不限」或 1 MB／10 MB／100 MB 以上
- **進階選項**：
  - 不要掃描這些資料夾（用資料夾挑選器加入）
  - 略過系統與程式資料夾（預設開）：Windows、Program Files、ProgramData、AppData、`.git`、`node_modules`、`site-packages`、`steamapps` 等，這些地方的重複通常是程式需要的
  - 包含隱藏的檔案與資料夾（預設關）

資源回收筒、System Volume Information、OneDrive 尚未下載的雲端檔案，以及經由 junction／符號連結看到的路徑一律不掃描。

### 2. 掃描中

畫面顯示三個步驟（列出檔案 → 快速比對 → 比對檔案內容）、進度、剩餘時間與磁碟類型，只有兩個按鈕：

| 按鈕 | 效果 |
|------|------|
| **暫停／繼續** | 暫停會真的停住磁碟讀取 |
| **停止** | 回到開始畫面；已比對過的部分都保留，可以隨時「繼續掃描」 |

直接關閉 DupeScan 也沒關係，下次開啟時可以從中斷的地方繼續。

### 3. 結果

```
5 組重複 · 最多可釋放 14.3 GB                      [重新掃描] [回到開始]
D:\Photos 等 2 個資料夾 · 2026-10-21 14:03 掃描 · 檢查了 12,345 個檔案   ⚠ 3 個檔案無法讀取
[搜尋檔名或資料夾        ] [全部類型 ▾] [排序：可釋放最多 ▾]
 ▾ day1.mp4   3 份 · 每份 3.9 GB                          移除 2 份，釋放 7.8 GB
    (保留)  day1.mp4        D:\Videos\trip      2023-11-15 06:13   最舊的
    (移除)  day1.mp4        E:\Backup\Videos    2023-11-16 06:13
    (移除)  day1 (1).mp4    D:\Downloads        2023-11-16 09:59
 ▾ IMG_0001.jpg   2 份 · 每份 5.1 MB                      移除 1 份，釋放 5.1 MB
    (保留)  IMG_0001.jpg    D:\Photos\2023      …                  原始檔名
    (移除)  IMG_0001 (1).jpg D:\Downloads       …
────────────────────────────────────────────────────────────────────────
將移除 3 個檔案，釋放 7.8 GB          [自動選取規則…] [移到資源回收筒（3 個）]
```

- 掃描完成時已經依[自動選取規則](#自動選取規則)選好每組要保留哪一份，「說明」欄寫著為什麼保留這份
- **點檔案前面的膠囊**切換「保留／移除」（或選取那一列按空白鍵）。每組至少保留一份；保護的資料夾裡的檔案顯示「保護」，一律保留
- 點群組那一列可以展開／收合；雙擊檔案用預設程式開啟；滑鼠停在圖片上會顯示縮圖
- 右鍵選單：開啟檔案、在檔案總管中顯示、只保留這一份、這組全部保留、這組依規則重新選取、複製路徑
- 上方可以搜尋檔名或資料夾（Ctrl＋F）、依類型篩選、依可釋放空間／份數／檔名排序；有篩選時底部會註明有幾個要移除的檔案不在目前的畫面上
- 「⚠ N 個檔案無法讀取」可以查看是哪些檔案、為什麼

## 自動選取規則

結果畫面底部的「**自動選取規則…**」。依下面的順序決定每組保留哪一份，前面的分不出來才看下一個：

| 順序 | 規則 | 說明 |
|------|------|------|
| 1 | **保護的資料夾** | 裡面的檔案一律保留，永遠不會被移除（例如整理好的相簿、備份） |
| 2 | **優先移除這些資料夾裡的副本** | 例如 Downloads、暫存資料夾；可以加入資料夾，或依名稱加入（任何位置名稱相同的資料夾都算） |
| 3 | **保留原始檔名**（預設開） | 「photo (1).jpg」「photo - 複製.jpg」「Copy of photo.jpg」「photo.jpg.dup1」、`+`／`%20` 代替空白的會優先移除，保留「photo.jpg」 |
| 4 | **其他情況保留** | 最舊的（預設）／最新的／路徑最短的 |

全部平手時保留第一份（群組內依路徑排序，每次結果一致）。按「套用」會重新選取所有群組，手動調整過的會被取代。

## 移除與還原

按「**移到資源回收筒**」會先檢查要移除的檔案還在、而且沒有變動，再顯示確認視窗：

- 一句話摘要：要移除幾個檔案、釋放多少
- 需要注意的事項：
  - 掃描後有變動或已經不在的檔案 → 不會移除
  - 系統或程式資料夾（Windows、Program Files、AppData、`.git`、Ollama 模型 blobs…）裡的檔案 → 預設不移除，要勾「仍要移除這些檔案」
- 「查看清單」展開每個檔案的處理方式

確認後在背景移除並顯示進度，完成後直接從結果拿掉，**不必重新掃描**。

| 移除方式（在設定中選） | 說明 |
|------|------|
| **資源回收筒**（預設） | 從 Windows 資源回收筒還原。網路磁碟、隨身碟、路徑超過 260 字元、回收筒停用或容量不足的檔案，會自動改用隔離資料夾；萬一 Windows 判斷某個檔案只能永久刪除，會先跳出警告讓你拒絕 |
| **隔離資料夾** | 搬到同一顆磁碟根目錄的 `.dupescan_quarantine`（瞬間完成），可在「⋯ → 操作紀錄與還原」一鍵還原；確定不需要後再自行刪除 |

設定中可以開啟「**移除前完整比對內容**」：移除前重新讀完「保留的那份」和要移除的檔案，內容不同的一律略過（比較慢，但最保險）。

## 中斷、當機與錯誤

| 狀況 | DupeScan 的處理 |
|------|------|
| 按「停止」、直接關閉視窗 | 留下續掃紀錄；開始畫面顯示「上次的掃描沒有完成」，按「繼續掃描」接著做，比對過的檔案不必重讀 |
| 掃描時出錯（磁碟拔掉、沒有回應…） | 掃描畫面顯示錯誤與「重試（從中斷處繼續）」「回到開始」，可查看詳細內容 |
| 當機、被強制結束、停電 | 下次啟動提示「上次 DupeScan 沒有正常關閉」並附上當機紀錄；未完成的掃描一樣可以繼續；掃描完成的結果有保存，可以直接開啟 |
| 程式內部錯誤 | 顯示錯誤視窗（可複製錯誤內容、開啟 log 資料夾），程式繼續執行；連續發生時合併在同一個視窗 |
| 快取檔損壞 | 自動改名備份並重建，掃描照常進行 |
| 快取正被另一個 DupeScan 使用 | 這次掃描不使用快取，結果畫面會註明 |
| 設定檔裡有讀不懂的值 | 改回預設值並提示 |
| 無法讀取的檔案 | 統計並列在結果畫面，不會默默漏掉 |

掃描完成、調整保留／移除、移除檔案之後，結果都會自動保存，當機也不會丟掉。

## ⋯ 選單與設定

視窗右上角的 **⋯**：

| 項目 | 說明 |
|------|------|
| 操作紀錄與還原… | 每次移除的結果；隔離資料夾的檔案可以一鍵還原 |

| 儲存目前的結果… | 存成 `.dupescan` 檔 |

| 開啟 log 資料夾 | 每次執行的紀錄與當機紀錄 |

## 掃描演算法

```
所有檔案
    │
    ▼ 第 1 步：列出檔案（只用目錄列舉帶回的資訊，不開檔），依大小分組
    │  ── 大小唯一的檔案不可能重複，直接排除
    │  ── 大小相同的候選查檔案 ID，合併同一個實體檔的多條路徑（硬連結）
    │
    ▼ 第 2 步：快速比對開頭 4 KB；8 MB 以上的再比對結尾 4 KB
    │  ── 4 KB 以下的小檔：開頭就是全部內容，直接確定
    │
    ▼ 第 3 步：前兩步都相同的才整檔比對（xxh3_128）
    │
    └─→ 重複群組（群組內依路徑排序，群組依可釋放空間排序）
```

- **雜湊快取**：第 2、3 步先查快取，大小與修改時間（奈秒）都沒變的檔案直接沿用；每 2 秒寫入一次，停止或當機最多損失幾秒的進度
- **讀檔排程**：每顆磁碟一個執行緒池——SSD／NVMe 平行讀取，HDD 單執行緒並依路徑順序讀（減少磁頭來回），不同磁碟同時進行
- **暫停與停止**：讀檔迴圈每讀一個區塊（1 MB）就檢查一次，暫停會真的停住讀取，停止也不必等大檔讀完

| 資料位置 | 內容 |
|------|------|

| `%LOCALAPPDATA%\DupeScan\journal.jsonl` | 操作紀錄 |
| `%LOCALAPPDATA%\DupeScan\reports\` | HTML 報表（保留最近 20 份） |
| `logs\`（專案資料夾內） | 執行紀錄（保留 30 份）與當機紀錄 |
| 各磁碟根目錄 `.dupescan_quarantine\` | 隔離資料夾 |

技術細節請參閱 [TECHNICAL.md](./TECHNICAL.md)。

## 常見問題

**Q: 移除後能復原嗎？**
A: 可以。送到資源回收筒的從 Windows 資源回收筒還原；移到隔離資料夾的在「⋯ → 操作紀錄與還原」一鍵還原。

**Q: 掃到一半想關機怎麼辦？**
A: 直接關閉 DupeScan 就好。下次開啟時按「繼續掃描」，已經比對過的檔案不必再讀。

**Q: 掃描很慢？**
A: 第一次掃描需要讀取候選檔案的內容；之後重掃同一個地方，沒變動的檔案直接沿用快取。也可以選比較大的「檔案大小」門檻、只比對特定類型，或在進階選項排除不需要的資料夾。

**Q: 為什麼有些檔案沒有出現在結果裡？**
A: 小於「檔案大小」門檻的、隱藏的、系統與程式資料夾裡的（可在進階選項打開）、OneDrive 尚未下載的、經由 junction／符號連結看到的路徑都不會比對。無法讀取的檔案會列在結果畫面的「⚠ N 個檔案無法讀取」。

**Q: 有一份正本，其他地方的都可以刪，要怎麼設？**
A: 在「自動選取規則」把正本所在的資料夾加進「保護的資料夾」。裡面的檔案一律保留，其他地方的副本照常標成移除。

**Q: 怎麼一次清掉「photo (1).jpg」「photo - 複製.jpg」這種重複下載的副本？**
A: 「保留原始檔名」預設就是開的，掃描完成時已經選好；也可以把 Downloads 加進「優先移除這些資料夾裡的副本」。

**Q: 刪掉一個「重複」會不會讓某個程式壞掉？**
A: 系統與程式資料夾預設不掃描；就算打開掃描，移除時也預設不動。若是 AI 模型等檔案在多個程式之間重複，移除前請確認那些程式不需要它。

**Q: 支援外接硬碟、網路磁碟嗎？**
A: 支援。網路與卸除式磁碟沒有資源回收筒，移除時會自動改移到該磁碟根目錄的隔離資料夾。
