# DupeScan — 重複檔案掃描工具

> 快速找出並清理磁碟中的重複檔案，釋放硬碟空間。**不會永久刪除任何檔案**：移除的檔案一律送到資源回收筒或隔離資料夾，都可以還原。

## 功能特色

**找重複**
- 掃描一個或多個資料夾／磁碟機，找出內容完全相同的檔案（可找出不同資料夾、不同磁碟之間的重複）
- 3-Pass 比對：依大小分組 → 前 4 KB 快速 Hash → 完整 xxHash，大幅減少磁碟讀取
- **雜湊快取**：記住上次算過的 hash，檔案沒變就不必再讀，重掃同一顆磁碟快很多；取消掃描時已算好的部分也會保留
- 自動偵測磁碟類型決定執行緒數（NVMe／SATA SSD 平行、HDD 循序）；多顆磁碟各用各的策略
- 不會被 junction、符號連結或硬連結騙：同一個實體檔經由不同路徑看到，不會被列成「重複」
- 自動排除資源回收筒、System Volume Information；預設略過隱藏／系統檔與 OneDrive 雲端佔位檔
- 掃描設定：最小／最大大小（KB／MB／GB）、只掃或排除特定副檔名、排除資料夾
- 暫停會真的停住磁碟讀取；取消或重置在讀大檔中途也能立刻生效
- 無法讀取的檔案會統計並列出（⚠ 略過 N 個），不會默默漏掉

**看結果**
- 虛擬化樹狀檢視：數萬個群組也能瞬間顯示、滑順捲動
- 預設依「可省空間」排序，另可依單檔大小、檔案數量、副檔名排序；副檔名篩選
- 摘要列即時顯示群組數、可省空間、已選檔案數與可釋放容量
- 雙擊開啟檔案；Ctrl＋點擊路徑在檔案總管中定位；圖片懸停預覽
- 鍵盤操作：方向鍵移動、空白鍵切換勾選
- 文字大小 9–18 px 即時調整

**選與移除**
- 9 種條件可疊加的批量快速選取（修改較新／較舊、路徑較短／較長、目錄較淺／較深、字母序、列表第一），也可在單一群組按右鍵套用
- **移除前預覽**：依群組列出保留／移除／略過，可搜尋、匯出 CSV，選擇送資源回收筒或隔離資料夾
- **防呆**：整組全選（一份都不剩）、受保護資料夾（Windows、Program Files、AppData、.git、Ollama 模型等）預設不移除；掃描後有變動的檔案自動略過
- 移除在背景進行並顯示進度；完成後直接更新結果，不必重新掃描
- **操作紀錄**：查看每次移除的結果，隔離資料夾的檔案可一鍵還原

**其他**
- 匯出 HTML 分析報表（副檔名圓餅圖）、完整結果 CSV
- 儲存結果（含勾選狀態），之後用「開啟結果」接著處理
- 記住上次的路徑、掃描設定、字級、排序、側邊列狀態與視窗大小
- 每次啟動產生一個 log（保留最近 30 份），記錄掃描與每一個被移除的檔案

## 安裝說明

### 方法一：一鍵啟動（推薦）

下載專案後，直接雙擊 **`run.bat`**。

腳本會自動：
1. 確認 Python 3.11+ 已安裝（若未安裝會提示下載連結）
2. 第一次執行時在專案內建立虛擬環境 `.venv` 並安裝相依套件（需要網路，約 100 MB；套件不會裝進全域 Python）
3. 之後只有 `requirements.txt` 變動才重新安裝，直接啟動 DupeScan（不留命令列視窗）

> 安裝 Python 時請勾選「**Add Python to PATH**」。
> 想看錯誤訊息時，在命令列執行 `run.bat debug`，會保留視窗。程式發生未預期的錯誤時，也會跳出提示並寫入 log。
> 相依套件壞掉時，刪除 `.venv` 資料夾再執行一次 `run.bat` 即可重建。

## 操作流程

### Step 1 — 選擇掃描路徑

點「**瀏覽**」選擇資料夾或磁碟機根目錄（如 `D:\`）。想同時掃多個位置：

- 按「**＋**」再加一個資料夾，或
- 直接把資料夾**拖進視窗**，或
- 在路徑欄輸入多個路徑，用 `;` 分隔：`D:\Photos; E:\Backup`

互相包含的路徑只會掃一次。

### Step 2 — 調整掃描設定（選用）

- 工具列「**最小**」：小於此大小的檔案不比對（預設 1 KB，可選 KB／MB／GB）
- 側邊列「**掃描設定**」：
  - 只掃這些副檔名／排除副檔名（例如 `jpg, png, mp4`）
  - 排除資料夾：名稱（任何位置，例如 `node_modules`）或完整路徑，以 `;` 分隔
  - 最大檔案大小（0＝不限）
  - 包含隱藏／系統檔（預設略過）
  - 使用雜湊快取（預設開啟）；「清除快取」只清 DupeScan 自己的快取，不會動到你的檔案

### Step 3 — 開始掃描

按「**▶ 開始掃描**」，進度列會顯示目前步驟與預估剩餘時間：

```
步驟 1/3 — 依檔案大小分組（不讀檔案內容）
步驟 2/3 — 快速 Hash 比對（前 4 KB）          預估剩餘: 約 30 秒
步驟 3/3 — 完整 Hash 比對（12/30 個檔案・3.2 GB / 40.1 GB）
```

| 按鈕 | 效果 |
|------|------|
| **⏸ 暫停** | 暫停掃描，真的停住磁碟讀取，可隨時繼續 |
| **▶ 繼續** | 從暫停點接續 |
| **✕ 取消掃描** | 中止掃描（讀大檔中途也會立刻停）；已算好的 hash 會存進快取，下次接著用 |
| **重置** | 停止並清除所有結果 |

### Step 4 — 查看結果

所有重複群組以**樹狀檢視**列出，預設依可省空間由大到小排序。點群組左側箭頭（或雙擊群組）展開檔案清單：

```
▼ 群組 #1     3 個重複     每個 2.4 MB     可省 4.8 MB
   ☐  photo_001.jpg   D:\Photos\2023        2.4 MB   2023-06-15 14:22
   ☑  photo_001.jpg   D:\Photos\備份\2023   2.4 MB   2023-06-15 14:22
   ☑  IMG_copy.jpg    C:\Users\Downloads    2.4 MB   2023-08-01 09:10
▶ 群組 #2     2 個重複     每個 1.1 MB     可省 1.1 MB
```

- 勾選檔案列的核取方塊＝標記待移除；群組列的三態核取方塊可一次切換整組
- **雙擊**檔案列以預設程式開啟；**Ctrl＋點擊**路徑欄在檔案總管中定位（右鍵選單也有）
- 鍵盤：方向鍵移動，**空白鍵**切換勾選（在群組列上切換整組）
- 滑鼠移到圖片檔名上會顯示縮圖
- 檔名後面的 ⛓N 表示這個檔案另有硬連結（同一份資料的其他路徑），不會被列成重複

摘要列：**X 個群組**、**可省 X**、**已選 N・容量**；若有無法讀取的檔案會出現 **⚠ 略過 N 個**（滑鼠移上去看明細）。

### Step 5 — 選擇要移除的檔案

側邊列「**批量快速選取**」可一鍵對所有顯示中的群組套用條件，條件可疊加（依勾選順序決定優先序），互相衝突的條件會自動停用：

| 條件 | 說明 |
|------|------|
| 修改較新／較舊 | 依修改時間 |
| 路徑較短／較長 | 依完整路徑字串長度 |
| 目錄較淺／較深 | 依目錄層數 |
| 字母較前／較後 | 依完整路徑字母序 |
| 列表第一 | 群組中的第一筆（群組內依路徑排序，每次結果一致） |

「保留目標」模式保留勝出者、勾選其餘；「刪除目標」模式只勾選勝出者。也可在單一群組上**按右鍵**套用。

### Step 6 — 移除

按「**🗑 移除已勾選**」會先開啟**預覽視窗**：

- 依群組列出每個檔案的動作：保留／移除／略過／受保護，可搜尋、匯出 CSV
- 選擇處理方式：
  - **資源回收筒**（預設）：可從 Windows 資源回收筒還原
  - **隔離資料夾**：搬到同一顆磁碟根目錄的 `.dupescan_quarantine`（同碟搬移瞬間完成），可在「操作紀錄」一鍵還原
- 需要注意的項目會列在上方：
  - ⛔ **整組全選**（移除後一份都不剩）→ 預設不移除，要勾「仍要移除」
  - 🔒 **受保護資料夾**（Windows、Program Files、AppData、.git、node_modules、Ollama 模型 blobs 等）→ 預設不移除，要勾「仍要移除」
  - ⚠ **掃描後有變動**（已不存在、大小或時間變了、開頭內容和保留的那份不同）→ 自動略過
- 可勾選「移除前完整比對內容」，重新讀完每個檔案確認仍與掃描結果相同（較慢，最保險）

確認後在背景移除並顯示進度。完成後直接從結果中拿掉已移除的檔案，**不需要重新掃描**。

> 進不了資源回收筒的檔案（網路／卸除式磁碟、路徑超過 260 字元、回收筒停用或容量不足）會自動改移到隔離資料夾；萬一 Windows 判斷某個檔案只能永久刪除，會先跳出警告讓你拒絕。

### 操作紀錄與還原

標題列「**↩ 操作紀錄**」列出每次移除的結果：

- 送到資源回收筒的檔案：請從 Windows 資源回收筒還原
- 移到隔離資料夾的檔案：選取該筆紀錄按「還原隔離的檔案」（原位置已有同名檔案時不會覆蓋）

確定不再需要之後，各磁碟根目錄的 `.dupescan_quarantine` 資料夾請自行刪除。

### 匯出與儲存結果

「**📊 匯出／儲存**」選單：

| 項目 | 說明 |
|------|------|
| HTML 分析報表 | 可釋放空間、群組數等統計，依副檔名的兩張圓餅圖與明細表（存在 `%LOCALAPPDATA%\DupeScan\reports`） |
| 完整結果 CSV | 每個檔案一列，Excel 可直接開啟 |
| 儲存結果 | 存成 `.dupescan` 檔（含勾選狀態），之後用標題列「📂 開啟結果」接著處理 |

## 掃描演算法

DupeScan 使用 **3-Pass 策略**，盡量不讀檔案內容：

```
所有檔案 (N 個)
    │
    ▼ Pass 1：遍歷目錄，依大小分組（只用目錄列舉帶回的資訊，不開檔）
    │  ── 跳過大小唯一的檔案
    │  ── 大小相同的候選查檔案 ID，合併同一個實體檔的多條路徑（硬連結）
    │
    ▼ Pass 2：讀取前 4 KB，快速 Hash（以「大小＋前段 Hash」分組）
    │  ── 跳過前 4 KB 不同的檔案（通常過濾 90% 以上）
    │
    ▼ Pass 3：對剩餘檔案做完整 xxHash
    │
    └─→ 確定重複群組（群組內依路徑排序，群組依可省空間排序）
```

- **雜湊快取**：Pass 2／3 先查快取，大小與修改時間（奈秒）都沒變的檔案直接沿用上次的 Hash
- **Hash 演算法**：優先使用 `xxHash`（比 MD5 快約 10 倍）；未安裝時自動改用 Python 內建 `blake2b`

## 常見問題

**Q: 刪除後能復原嗎？**
A: 可以。DupeScan 不會永久刪除檔案：送到資源回收筒的從 Windows 資源回收筒還原；移到隔離資料夾的在「操作紀錄」一鍵還原。

**Q: 掃描速度很慢？**
A: 第一次掃描需要讀取候選檔案的內容；之後重掃同一個地方，沒變動的檔案會直接沿用快取，只剩遍歷目錄的時間。也可以提高「最小」大小、只掃特定副檔名或排除不需要的資料夾。

**Q: 為什麼有些檔案沒有出現在結果裡？**
A: 預設會略過隱藏／系統檔、資源回收筒、OneDrive 尚未下載的雲端檔案，以及經由 junction、符號連結看到的重複路徑。若摘要列出現「⚠ 略過 N 個」，滑鼠移上去可以看到無法讀取的檔案與原因。不建議以系統管理員身分執行來掃描系統資料夾。

**Q: 為什麼勾了卻沒有被移除？**
A: 移除前會再檢查一次：整組全選、受保護資料夾預設不移除（要在預覽視窗勾「仍要移除」）；掃描後有變動的檔案會自動略過。略過的原因會顯示在預覽視窗與 log 裡。

**Q: 刪掉一個「重複」會不會讓某個程式壞掉？**
A: 程式自己管理的資料夾（例如 Ollama 的 `models\blobs`、`.git`、`node_modules`、AppData）預設受保護。若是 AI 模型等檔案在多個程式之間重複，移除前請確認那些程式不需要它。

**Q: 支援外接硬碟、網路磁碟嗎？**
A: 支援。網路與卸除式磁碟沒有資源回收筒，移除時會自動改移到該磁碟根目錄的隔離資料夾。
